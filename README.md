# 財經 YouTube 內容成效分析與機器學習預測｜小Lin說案例

專題作者：方柏登／施建宏。此頁呈現共同研究成果，不將全部團隊工作歸為個人獨立完成。

## 研究問題
發布前可以取得的題材、標題、片長與發布時間，是否包含歷史高成效訊號？研究目標是輔助內容企劃判斷。

## 資料與流程
以 YouTube Data API v3 取得公開影片資料，162 部公開影片篩選為 156 部一般長影音。2020–2025 年共 142 部用於模型建立與評估，2026 年 14 部只做潛力排序，不參與訓練或模型調整。

- 使用題材、標題長度、有無數字、有無問號、片長、發布星期與發布時段共七項發布前特徵。
- 以各年度日均觀看數前 25% 定義 High，其餘為 Normal。
- 觀看數、按讚數與留言數不納入輸入特徵，避免資料洩漏。
- 比較邏輯斯迴歸（LR）與隨機森林（RF），分開解讀固定測試集與訓練集五折交叉驗證。

## 結果
固定測試集 29 部中，RF 的 F1 為 70.00%、召回率為 87.50%；LR 在門檻 0.60 的 F1 為 58.82%。五折平均 F1 則為 LR 0.5321、RF 0.4785，不能因此宣稱 RF 全面較佳。片長是 EDA 與兩種模型較一致的觀察訊號，但不能推論影片越長成效越好。

## 限制
單一頻道、142 部模型樣本。日均觀看數是代理指標，API 資料缺少 CTR 與觀眾留存。研究不是因果推論，2026 影片尚無正式真實標籤，模型分數不等於實際爆款機率。
